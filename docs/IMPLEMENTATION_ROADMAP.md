# Job Browser Implementation Roadmap

## Current Status

- Phase 7: Provider Expansion
- After iCIMS: Enable approved public providers and perform bounded discovery runs. Browser-backed providers remain opt-in and must respect each site's terms, robots policy, login controls, and security checks.
- Use the application for real job hunting before adding major
  features.

## Phase 8

- Application tracking
- Resume intelligence
- Company intelligence
- AI assistant
- Discovery health dashboard

## Guiding Principles

1.  Finish one feature completely.
2.  Verify with tests.
3.  Update documentation.
4.  Do not begin the next feature until the current one is
    production-ready.

## Boundary

Application tracking, resume intelligence, company intelligence, and the AI
assistant remain Phase 8 planning items. The current release closes the
discovery/source-management phase first; it does not claim those planning
tables or workflows are implemented.
